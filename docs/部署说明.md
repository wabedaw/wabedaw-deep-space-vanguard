# 深空先锋 · Deep Space Vanguard — 网站部署说明

## 包里有什么

```
deep-space-vanguard/          ← 整个文件夹原样上传到网站
├── index.html                游戏本体（单文件，约 660 KB，gzip 后约 184 KB）
├── manifest.webmanifest      手机"添加到主屏幕"用
├── og-image.jpg              分享预览图 1200×630
├── icons/                    网站图标、苹果触屏图标、PWA 图标
└── fonts/                    自托管字体（Chakra Petch、Barlow、Noto Sans SC 子集）+ 授权文件
promo/                        宣传图（不用上传，给运营/商店页用）
├── cover-square-en-1080.jpg  英文正方形封面 1080×1080
├── cover-square-en-2160.jpg  英文正方形封面 2160×2160（高清）
└── share-image-1200x630.jpg  社交分享图
```

纯静态文件，不需要后端、数据库或构建步骤，也不会向任何外部服务器发请求。

## 1. 上传

把 `deep-space-vanguard/` 文件夹上传到网站任意路径，例如：

```
https://你的域名/games/deep-space-vanguard/
```

所有资源都用相对路径，放在哪一层目录都能用。建议使用 HTTPS。

## 2. 服务器设置（建议）

大多数服务器默认就能正常工作。以下是推荐优化：

- **开启 gzip 或 brotli 压缩**：index.html 可以从约 660 KB 压到约 184 KB。
- **MIME 类型**：`.woff2` → `font/woff2`，`.webmanifest` → `application/manifest+json`（新版 Nginx/Apache/CDN 一般已内置）。
- **缓存**：`fonts/`、`icons/` 可以长期缓存；`index.html` 建议 `no-cache`，以后更新游戏时玩家能立刻拿到新版。

Nginx 参考配置：

```nginx
location /games/deep-space-vanguard/ {
    gzip on;
    gzip_types text/html text/css application/javascript application/manifest+json;
    location ~* \.(woff2|png|jpg)$ { expires 30d; add_header Cache-Control "public"; }
    location ~* \.html$          { add_header Cache-Control "no-cache"; }
}
types { font/woff2 woff2; application/manifest+json webmanifest; }
```

## 3. 打开方式

**方式 A：直接链接（推荐）**

```html
<a href="/games/deep-space-vanguard/">开始游戏</a>
```

全屏体验最好，手机上也可以"添加到主屏幕"像 App 一样打开。

**方式 B：嵌入到页面里（iframe）**

```html
<div style="position:relative;width:100%;aspect-ratio:16/9;max-width:1280px;margin:auto">
  <iframe src="/games/deep-space-vanguard/"
          style="position:absolute;inset:0;width:100%;height:100%;border:0"
          allow="fullscreen; autoplay"
          title="深空先锋 Deep Space Vanguard"></iframe>
</div>
```

注意：嵌入时玩家需要先点一下游戏画面，键盘操作才会生效（浏览器的焦点规则）。

## 4. 语言

- 默认跟随浏览器语言：中文浏览器显示中文，其他显示英文。
- 玩家可以在游戏内切换，选择会被记住。
- 链接末尾加 `#zh` 或 `#en` 可以强制指定，例如 `/games/deep-space-vanguard/#en`。

## 5. 分享预览（微信 / 社交平台）

`index.html` 里的 `og:image` 现在是相对路径 `og-image.jpg`。部分平台（微信、Facebook 等）要求绝对地址，上线后请改成完整网址：

```html
<meta property="og:image" content="https://你的域名/games/deep-space-vanguard/og-image.jpg">
```

可以再加一行 `<meta property="og:url" content="https://你的域名/games/deep-space-vanguard/">`。

## 6. 排行榜

网站版的排行榜显示**这台设备上的最好成绩**（本机排行）。Claude 里的版本是全球排行，因为那里有内置数据库；放到自己的网站上没有这个数据库。

如果要做全球排行榜，需要一个简单的后端接口（提交成绩 + 读取前 100 名），之后可以接入。

## 7. 存档

存档和设置保存在玩家浏览器的 localStorage 中，按域名隔离：

| 键名 | 内容 |
|---|---|
| `dsv-best` / `dsv-stage` | 最高分 / 最远关卡 |
| `dsv-last` | 上次飞到的关卡（首页"继续"按钮用） |
| `dsv-cleared` | 是否通关 |
| `dsv-runs` / `dsv-call` | 本机排行记录 / 呼号 |
| `dsv-lang` / `dsv-sound` | 语言 / 音效开关 |
| `dsv-tut` | 新手指引进度 |
| `dsv-dev` / `dsv-dev-opts` | 开发者模式 |

换域名或换浏览器后存档不会跟过去。

## 8. 开发者模式

首页的开发者模式入口所有人都能看到，但需要密码：**`dsv2026`**。开发者模式下的成绩不会计入排行榜。

如果正式上线时想隐藏入口或更换密码，告诉我即可。

## 9. 授权
