# 翻译说明：繁體中文（台湾）与日本語

本文件说明 `zh-Hant.json` 和 `ja.json` 的译法依据，供母语校对者参考。

- **范围：** `catalog.csv` 共 407 条。开始翻译时是 404 条；翻译期间代码新增了 3 条手柄相关文字（`Gamepad`、手柄按键说明、`Auto fire · OFF (hold RT to fire)`），也一并译了。
- **键：** 两个 JSON 的键与 catalog 的 English 列逐字一致；`{0}`、`<small>`、`<span>` 等标签，以及开头、结尾的空格和「 · 」都保持不变。
- **依据：** 以简体中文为主要含义来源，再看代码上下文判断字符串是 HUD 标签、按钮、提示条（toast），还是要和数字拼接的片段。
- **检查：** `node tools/i18n.mjs` 结果为 `zh-Hant: 0 missing`、`ja: 0 missing`。这个命令会顺带重写 `catalog.csv`，把两列译文填进去，这是工具本身的行为。

## 总体原则

**繁體中文**

- 用台湾惯用词，不做机械转换，例如：雷射、飛彈、螢幕（全螢幕爆炸）、滑鼠、訊號、模組、反應爐、登入、裝置、帳號、即時、檢視、儲存、重設、重新整理、拖曳、空白鍵、橘色、菁英、砲台、砲塔、手把、紀錄（名词：最高紀錄、新紀錄）。关卡的「关」一律写作「關」（關卡、通關、關底BOSS）。
- 用字依台湾教育部标准字形：著陸、裡、汙染、稜鏡、稜晶、啟、為。
- 专有名词（星座、神话名、音译名）按简中转繁，例如：獵戶座、柯伊伯、赫利俄斯、塞壬、利維坦、奧米伽。
- 简中保留英文的地方，繁中也保留，例如「得分 SCORE」「STAGE CLEAR · +」、Boss 名后面的「 · SIREN」，以及 `<small>` 里的英文副标题。

**日本語**

- 武器和 Boss 等级名用片假名，例如：ベガ・ランス、スプレッド、ビーム、ノヴァ・パルス、セイレーン級、フェニックス級。舰种用汉字，例如：母艦、戦艦、攻撃艦、空母。
- 机体代号 V-7 VEGA，以及 W、M、MK.X、AU、M☉、ENTER、ESC、RT 等保留拉丁字母。
- 地名尽量意译，并采用日本天文术语，例如：オリオン腕外縁、わし座暗流、事象の地平線回廊、重力レンズ域、銀河中心放射帯。
- 战斗提示多用体言止め（名词结尾），例如「コアを攻撃！」「全砲門開放」。教学和系统说明用简短的です・ます体。HUD 标签和按钮不加「。」，只有一处两句话相连的提示里用了句中的「。」。
- 简中把「Boss 名 · 英文代号」并排显示，日文保留这种格式。

## 优先校对清单

下面 26 条是译者没有把握，或受版面限制做了取舍的地方，建议母语校对者先看。编号只用于本清单，不对应 catalog 行号。

### 双关、文风与标题

1. **日文标题**「アッシュウィング：スレイ・ザ・ファーストライト」：按开发计划「日文按英文名音译」处理。要确认两处写法：ウィング 还是 ウイング，ファーストライト 中间要不要加「・」。
2. **日文 Logo**：标题画面主标题保留「ASHWING」。原因是 CJK 样式下 `.ht-main` 字号约为 12vw，8 个片假名会超出手机屏宽。副标题用「スレイ・ザ・ファーストライト」。需要确认这种中英混排的 Logo 是否可以接受。
3. **The First Light**：游戏内文本用「始源之光」，世界观文档用「初光」。译文跟随游戏文本（始源之光 / 始源の光）。如果以后统一成「初光」，两种语言都要一起改。
4. **结局句**「始源の光、ここに消ゆ」用了文语「消ゆ」，对应简中「始源之光，已然熄灭」的诗意。「新たな星々が、君の航跡に生まれる」里用「君」称呼玩家。这两句都需要确认语气。
5. **HUD「SCORE」**：简中是「得分 SCORE」，繁中照搬。日文只写「SCORE」，因为写成「スコア SCORE」会重复；日本射击游戏的 HUD 也习惯写英文。
6. **关底奖励「BONUS +」**：简中是「STAGE CLEAR · +」，繁中照搬。日文主横幅已经显示「STAGE n CLEAR」，所以副行改成「ボーナス +」。
7. **黑洞死亡标题**：英文 `<small>` 写的是 PAST THE POINT OF NO RETURN，简中写的是 CONSUMED BY SINGULARITY，两种译文都跟随简中。日文主标题「特異点に消失」是为了配合大字号而压缩的写法，需要确认。

### 长度偏紧

8. **日文武器按钮「スプレッド」**：触屏按钮是 60px 的圆形，字号 12px，5 个假名大约 64px，可能折成两行。用户指定 Spread 译为「スプレッド」，所以没有改用「拡散」。如果实机效果不好，可以考虑改成「拡散」。
9. **日文 HUD 飞弹标签保留「MSL」**：飞弹格子从第 30px 开始画，写「ミサイル」会盖住格子。
10. **日文「ノヴァ準備完了」（7 字）**：简中「脉冲就绪」是 4 字，9.5px 小字，显示在充能条右侧，需要确认宽度够不够。
11. **日文「スプレッドレーザー」「ビームレーザー」**：HUD 左下的武器名，后面还会接「MK.VIII · バースト」和等级格子。手机竖屏下要确认不会超出屏幕。
12. **日文小 Boss 简称**：「サンダーバード級」「スカイホエール級」「フロストウィング級」「アイスブレイカー級」等有 7–9 字，简中只有 3 字。它们用在提示条「護衛艦接近 · ○○級」里。提示条会自动缩小字号，但缩得较多。
13. **日文「飛行ガイド」**：没用更常见的「フライトガイド」，因为教学卡片标题和标签在同一行，手机上较窄。
14. **日文「続きから」**：读档继续按钮的字距很大（.42em），所以选了 4 字的写法，而不是「コンティニュー」。

### 术语和译法上的猜测

15. **PRISMARCH CRYSTAL OVERMIND**：日文「プリズム支配体」，同一组的星域名「Overmind Domain」译为「支配体の領域」。这是自造译法，可以考虑「プリズム・オーバーマインド」。
16. **Dreadnought**：日文 HYDRA、GLACIER 都译为「戦艦」，没有用「弩級艦」。
17. **ICEBREAKER-CLASS RAM SHIP**：按简中「重舰」，日文译为「重装艦」，没有用英文 ram 对应的「衝角艦」。
18. **Forge**：日文统一用「溶鉱炉要塞」「溶鉱炉工業区」，也可以用片假名「フォージ」。
19. **NO-RETURN LINE**：日文用航空术语「帰還不能点」的说法，译为「帰還不能線」。也可以考虑「脱出不能ライン」。
20. **CONSUMED（敌机被黑洞吞噬时的飘字）**：日文「吸い込まれた」。**GRAVITY PULL**：日文「引力圏内」。
21. **Enraged**：日文用「暴走モード」，没有用射击游戏圈的行话「発狂」。
22. **自造地名**：「虫巣外縁」「巣核外壁」「双環巣星」「巣網深部」是按简中直译的组合词，日文读起来可能生硬。
23. **Escort inbound**：简中「护卫舰回援」带有「回来支援」的意思，日文「護衛艦接近」没有保留这一层。
24. **日文语气**：黑洞教学用「オレンジの点線の外側を飛ぶこと」这种指示口吻；排行榜里的「YOU」译为「あなた」。

### 繁中用词取舍

25. **地名中的词汇**：
    - 「引力透镜区」改用台湾天文惯用的「重力透鏡區」。
    - 「反应堆」改为「反應爐」。
    - 「冰川」在专有名词里保留，没有改成台湾更常见的「冰河」。
    - 「柯伊伯」保留，没有改成台湾的「古柏帶」。

    需要母语者决定这几处是否统一。另外「護盾產生塔」（简中「发生塔」）、「菁英」、「手把」、「全螢幕爆炸」也请确认。
26. **新增的 3 条手柄文字**：翻译期间代码新加的「Gamepad」「左搖桿移動 · A 飛彈 · …」「自動射擊 · 關（按住 RT 射擊）」不在最初的 404 条里。它们的上下文较少，建议一并核对。
